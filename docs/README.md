## 归属约定（新增文档时先判断）

| **待办、规划**、尚未实现的设计 | `未完成/` |

| **现状快照**、**跨类规范** | 根目录 |

## 维护规则

1. **移动/重命名后必须全仓 grep 旧路径并更新**——包括 **Go 代码注释里**的文档路径。
   ```bash
   # 检查残留（把 docs/ 后面接的旧名换掉）
   grep -rn 'docs/旧名\.md' --include='*.md' --include='*.go' .
   ```
2. `已完成/` 的文档若含未实现章节，**必须在状态行标注**（例：「已实现；X 部分未接线」）。
3. 新增文档 → 先判断归属 → 再更新本索引的表格。
4. **文档只信证据**：任何"已实现/未实现"的断言，写之前先核实代码。
