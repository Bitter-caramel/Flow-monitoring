# 解析器

本文说明抓包文件的解析流程：pcapng 怎么读、包怎么解码（L2→L7），以及几个关键的格式细节。

代码位置：`internal/modules/parse/`（`pcapng/reader.go` + `decoder/`）。

## 1. 概览

解析分两层：

1. **pcapng 容器层**（`parse/pcapng`）：把文件切成"区块"，读出接口信息、时间戳、原始包字节。
2. **协议解码层**（`parse/decoder`）：对每个包的字节，从链路层逐层解码到应用层。

## 2. pcapng 区块格式

pcapng 由一系列「区块（Block）」顺序排列组成，每块结构为：

```
类型(4B) + 长度(4B) + 正文(变长，4字节对齐) + 长度(4B, 与开头一致)
```

| 区块 | 类型值 | 作用 |
|---|---|---|
| SHB | `0x0a0d0d0a` | Section 头：版本、字节序锚点、元信息 |
| IDB | `1` | 接口描述：链路类型、snaplen、时间戳精度/偏移 |
| EPB | `6` | 增强包块：**真正的数据包**（接口、时间戳、捕获长度、原始字节） |
| SPB | `3` | 简单包块：只有原始长度，无时间戳/接口 |
| NRB | `4` | 名称解析记录 |
| ISB | `5` | 接口统计 |
| DSB | `10` | 解密密钥块（TLS keylog 等） |

### 2.1 字节序

- 文件魔数 `0a 0d 0d 0a` 是回文，两端读都一样。
- SHB 的正文第 8 字节是 BOM：`4d 3c 2b 1a` = 小端，`1a 2b 3c 4d` = 大端。之后整节按此字节序读。
- **一个文件可含多个 section，字节序可中途改变**，读每个块都要用当前节的字节序。

### 2.2 时间戳

- EPB 的时间戳是 64 位：`高32位 * 2^32 + 低32位`（组合前先转 uint64）。
- 再按该接口的 `if_tsresol`（十进制 `10^n` 或二进制 `2^n`）换算成秒/小数，并加 `if_tsoffset` 偏移。
- 时间精度：`tsresol=6` 表示微秒，`9` 表示纳秒。

### 2.3 4 字节对齐

EPB 数据区之后、选项区之前有 padding：选项区起点 = `正文起点 + 20 + caplen + ((4 - caplen%4) % 4)`。数据区本身可能因文件截断而实际可用字节 < caplen，必须做边界检查，不能盲信块头长度。

## 3. 解码流程

```
decode(包字节, 链路类型)
  ├─ link()  链路层分发：Ethernet / raw IP / loopback / SLL / 802.11 …
  │    Ethernet → EtherType 展开：VLAN / MPLS / PPPoE（递归，需深度保护）
  ├─ ip4() / ip6()  网络层：IPv4 分片、IPv6 扩展头、隧道（GRE/IPIP…）
  ├─ tcp() / udp() / icmp()  传输层：端口/标志位/校验和
  └─ dispatch()  L7 识别：
       UDP 端口优先（DNS/DHCP/NTP/SNMP…），
       TCP 内容嗅探优先（TLS 记录头/HTTP 特征/SSH banner/SMB…）
```

每个包解码都带 `panic-recover` 容错：单个畸形包不中断整个文件，只标记 `mal`（解析异常）或 `ckbad`（校验和错误）。

## 4. 关键解析要点（易错处）

1. **字节序中途切换**：多 section 文件各自字节序，不能用固定小端读全程。
2. **EPB 对齐与截断**：选项区起点要考虑 4 字节 padding；数据区实际字节可能 < caplen，要按可用长度截断并记录 warning。
3. **64 位时间戳**：`hi*2^32+lo` 组合前先转 uint64，避免溢出。
4. **接口回退**：EPB 引用不存在的接口 id（损坏文件）时，回退到 `ifaces[0]` 或默认 Ethernet，避免空指针。
5. **无 IDB 的 pcapng / 只有 SPB**：默认链路类型按 Ethernet 处理，包无时间戳。
6. **VLAN/MPLS/PPPoE 递归**：展开深度需显式上限（如 8~16），防恶意嵌套构造无限递归。
7. **IPv4 分片**：非首片没有 L4 头，只标记 `fragmented`，端口由分析期用同四元组首片补齐；当前实现不做分片重组。
8. **坏块策略**：pcapng 遇到坏块直接终止（不做滑动恢复）。
